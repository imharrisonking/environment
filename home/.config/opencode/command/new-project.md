# New Project Discovery

Invoke the Architect agent to begin **Phase 1: Overview Discovery**.

## The Workflow

The Architect will guide you through a deep discovery process to establish the project's foundation. This is not just a form-filling exercise; it is a design session.

### Phase 1: Overview (Vision & Scope)
*   **Artifact:** `docs/OVERVIEW.md`
*   **Focus:** The "Elevator Pitch", In/Out of Scope, Core Concepts.

### Phase 2: Architecture (The Technical "How")
*   **Artifact:** `docs/ARCHITECTURE.md`
*   **Focus:** Tech Stack, Directory Structure, Key Design Decisions.

### Phase 3: Status & Roadmap (The Plan)
*   **Artifact:** `docs/STATUS.md` & `specs/plan/00-overview.md`
*   **Focus:** Breaking the project into sequential implementation phases.

## How to use
1.  Run `/new-project [Idea]`.
2.  Answer the Architect's questions. Be detailed!
3.  The Architect will generate the documentation files for you.

## Example
```
> /new-project A collaborative whiteboard app

Architect: I've initialized the project. Let's start with the Vision.
           What is the core problem this solves, and for whom?
```
